# Blogger Theme Recommendation

## Pick: **Blogger's built-in "Notable" theme** (free, official Google theme)

Why this over random third-party themes:
- Officially maintained by Blogger → no malware/bloated code risk (a real reason some AdSense reviews stall — hidden scripts, popups, or slow third-party themes hurt "site quality" signals).
- Mobile-responsive out of the box (passes Google Mobile-Friendly Test without tweaking).
- Fast-loading — minimal CSS/JS compared to downloaded "magazine" themes stuffed with sliders/carousels.
- Clean single-column-with-sidebar layout = natural, non-intrusive ad placement zones (top of sidebar, in-article, end-of-post) without needing to hack the template.
- Built-in support for featured images, labels (great for internal linking by category: "Budget Destinations", "Itineraries", "Food & Culture", "Travel Tips", "Packing Guides").

### Alternative free options (if you want a different look)
1. **Emporio** (Blogger official) — good for a more magazine/photo-heavy travel look, still lightweight.
2. **Soho** (Blogger official) — minimal, blog-first, very fast.
3. Avoid random "free travel blogger template" ZIP downloads from third-party sites — many inject hidden ad scripts or affiliate redirects that Blogger flags during AdSense review.

## Setup checklist after picking theme
- [ ] Set a custom favicon (simple logo/icon, even text-based via Canva)
- [ ] Add a clear logo/title in header (Blog name + tagline)
- [ ] Create a top navigation menu: Home | Destinations | Itineraries | Travel Tips | Packing Guides | Food & Culture | About | Contact | Privacy Policy
- [ ] Enable "Custom Robots.txt" and "Custom robots header tags" in Settings → Crawlers and indexing (helps SEO indexing)
- [ ] Set up labels/categories consistently on every post (used for internal linking + sidebar widget)
- [ ] Add an "About the Author" gadget in sidebar for trust signal
- [ ] Compress all images before upload (TinyPNG) — page speed matters for both AdSense and SEO
- [ ] Remove unnecessary gadgets (Popular Posts is fine; avoid link-list widgets to random external sites)
